# NOVATERRA reference parity

Reference images provided in the conversation are visual design targets, **not** proof of implemented features.

## Screen-by-screen acceptance
- Splash: logo, scene composition, launch CTA and platform branding.
- Main menu: continue, new game, multiplayer, worlds, settings, shop, exit.
- World selection: saved worlds, create, import, copy and delete.
- Avatar customization: skin selection and preview.
- Gameplay: hearts, coordinates, time, hotbar, minimap and touch controls.
- Inventory/crafting: responsive grids, categories, recipes and equipment.
- Map: world markers, zoom and player location.
- Settings: graphics, controls, audio, accessibility.
- Multiplayer: actual server discovery and connection, not static mock data.
- Survival/RPG: real progression, farming, enemies and quests.

Each screen needs reference comparison at Android phone, Android tablet and Windows desktop resolutions, plus interaction tests. Current parity is **unverified**. No fake working buttons or placeholder server listings are acceptable.
