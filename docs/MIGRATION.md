# NOVATERRA — Android-only migration

The original NOVATERRA v1.1.0 source and its 17 original PNG textures have already been imported into GitHub. Four additional survival HUD textures bring the game total to 21 PNG assets.

The shared game includes world generation, mining, crafting, furnace, map, survival, creatures, and RPG progression.

NOVATERRA now targets **Android only**. The Windows application and iOS prototype have been deleted from the current repository tree.

The historical source archive remains for read-only verification. It must not overwrite newer game code.

The Android APK embeds the Luanti native game engine and an offline-only main menu. Development builds and tests are automated. Full device verification, offline airplane-mode validation and exact reference-image comparison remain outstanding.
