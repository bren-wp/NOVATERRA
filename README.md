# NOVATERRA

**Voxel survival / crafting RPG for Android and Windows.**

## Project status

The project is in **development**. A Luanti game prototype exists in a separate source archive (v1.1.0-dev), but **its complete source has not yet been imported into this repository**. Do not treat this repository as a playable release.

### Planned modules
- Procedural terrain, biomes, ores and trees
- Block placement, mining, tools and crafting
- Hunger, health and inventory
- Furnace and resource processing
- Custom menus and mobile HUD
- Android APK/AAB and Windows builds

### Quality gates
1. Import the actual source tree from the development archive, preserving original files.
2. Validate Lua syntax and mod dependencies.
3. Run automated tests and Luanti smoke tests.
4. Build and launch on Windows and Android.
5. Compare each screen against approved NOVATERRA reference images.
6. Publish a release only with verified build artifacts.

**Important:** The images are design references, not evidence of implemented gameplay. Visual 1:1 parity and cross-platform runtime have not been verified.
